# GIGAribo Mobile

Standalone source project for the local GIGAribo Expo demo.

Website: https://gigaribo.onrender.com/

## Run locally

Requirements: Node.js and npm.

```sh
npm install
npm run web
```

To open the native Expo development menu and use Expo Go, run:

```sh
npm start
```

Scan the QR code with Expo Go, or press `w` in the terminal to open the web preview.

## Demo behavior

- Sign-in, registration, and verification are simulated. Any four digits pass the verification preview.
- Services and prices are sample content.
- Requests, checkout choices, favorites, and profile details are saved locally on the device/browser.
- No real account authentication, provider booking, or payment processing is connected.

The project archive contains source files and image assets, not installed dependencies or an Android/iOS install package.
